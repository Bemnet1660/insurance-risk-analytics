# Insurance Risk Analytics & Predictive Modeling

[![CI](https://github.com/your-username/insurance-risk-analytics/actions/workflows/ci.yml/badge.svg)](https://github.com/your-username/insurance-risk-analytics/actions/workflows/ci.yml)

## Project Overview

This project delivers an end‑to‑end analytical solution for AlphaCare Insurance Solutions (ACIS).  
The goal is to analyse 18 months of historical car insurance data (Feb 2014 – Aug 2015) to:

- Identify low‑risk customer segments where premiums could be reduced.
- Statistically validate risk drivers across provinces, zip codes, and gender.
- Build predictive models for claim severity and claim probability to enable risk‑based pricing.

The work is organised into four tasks, each on a separate branch:

| Task | Branch     | Description                                                                 |
|------|------------|-----------------------------------------------------------------------------|
| 1    | task-1   | Exploratory Data Analysis (EDA) & CI setup                                 |
| 2    | task-2   | Data Version Control (DVC) with local remote storage                       |
| 3    | task-3   | A/B hypothesis testing (claim frequency, severity, margin)                 |
| 4    | task-4   | Predictive modeling (Linear Regression, Random Forest, XGBoost) + SHAP     |
